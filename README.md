# Java-DSA

Welcome to the **Java-DSA** repository! This project is dedicated to providing comprehensive Java implementations of fundamental data structures and algorithms. Whether you're a beginner aiming to grasp the basics or an enthusiast looking to deepen your understanding, this repository serves as a valuable resource.

## 📚 Contents

The repository is organized into the following categories:

- **Sorting Algorithms**: Implementations of common sorting techniques.
  - `BubbleSort.java`
  - `MergeSort.java`
  - `QuickSort.java`

- **Data Structures**:
  - `LinkedListQuestions.java`: Various problems and solutions related to linked lists.

- **Miscellaneous**:
  - `Diamond.java`: A program to print diamond patterns.
  - `Integer.java`: Integer manipulation examples.
  - `NoPyramid_palindrome.java`: Checks for palindrome patterns in pyramids.
